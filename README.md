# Titanic Data Analysis

A data analysis project using the Titanic dataset and Python.

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Description
This project focuses on cleaning and analyzing the Titanic dataset. It includes checking missing values, duplicate records, outliers, and data types.

It also explores passenger survival based on gender, age, ticket class, fare, and family members using data analysis and visualization.

## Dataset
The Titanic dataset is loaded from Seaborn.

## Analysis
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Survival Analysis
